# Meta Muse Spark & Muse Code

Guide for integrating Meta's Muse Spark 1.2 models and Muse Code terminal agent into developer workflows.

## Features
- **Muse Spark 1.2**: Coding-focused update with enhanced long-horizon capability and self-improvement loops.
- **Muse Code**: Terminal coding agent featuring async background agents, event logs, and restart-safe state recovery.
- **Muse Glimmer**: 30B dense model optimized for local tool calling, featuring native vision and an MIT license.

## Usage Patterns
- Pair Muse Spark with Muse Code for repository-wide generation tasks.
- Use Muse Glimmer for local, offline agent loops requiring reliable tool calling and low latency.
