# Self Improving Skill — Enriquecimentos (YouTube 2026-09-20)

## Bike method (Nate Herk) — YouTube 2026-09-20

- Fonte `9KOtMsZ9I28` (Nate Herk, "How to Build Codex Skills Better than 99% of People"), passo 6: skill nunca está pronta (fora do caso super-determinístico) — a cada run, dar feedback do que gostou E do que não gostou e mandar atualizar a skill (ex.: "screenshots 1–2 ruins, frame no meio de animação, 4 imagens enfileiradas = verificação fraca; atualize para não repetir").
- Colocar a skill para rodar o próprio feedback loop: agent build → (sub)agents verify → V2…V15 até aprovar; exigir QA report como prova de verificação (título, corpo, N blocos, screenshots, headings, revisão visual/privacidade, cobertura editorial, artefatos) — sem QA report, a skill degrada (screenshots no lugar errado).
- Guardrails permanecem enquanto a confiança sobe (rodinhas → cotoveleiras → capacete nunca sai na highway): skill melhora, mas supervisão não vai a zero.
