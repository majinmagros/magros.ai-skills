# Skill: Analise-concorrentes — o que o concorrente faz hoje

Levanta o que os concorrentes do nicho estão rodando AGORA (anúncios, ofertas,
funis, hooks, credibilidade) e vira relatório acionável. Não é opinião:
é leitura de dados públicos.

## 1. Fontes primárias

- **Meta Ads Library** (facebook.com/ads/library) — anúncios ativos por
  anunciante: criativos, formatos, CTA, páginas de destino.
- **Landing pages dos concorrentes** — extrair: headline, oferta, prova social,
  estrutura do funil, preço/entry offer, high-ticket.
- **Pesquisa social** (`pesquisa-social`) para sentimento/reputação.

## 2. O que extrair

| Bloco | Pergunta |
|---|---|
| **Formatos** | Vídeo talking-head, estático, carrossel, UGC? |
| **Hooks** | Primeiros 3s / headline — o que captura atenção |
| **Oferta** | Lead magnet grátis, tripwire (produto físico 10x), curso, high-ticket |
| **Funil** | Sequência: inscrito → leitor → membro da comunidade → venda cara |
| **Credibilidade** | Recordes, avaliações (ex.: 4.9 Amazon), autoridade |
| **Insights** | Padrões: volume > perfeição criativa, produto físico atrai mais que PDF, etc. |

## 3. Processo

1. Liste os concorrentes-alvo e as plataformas (Ads Library, landing pages).
2. Varra criativos + analise cada landing page.
3. Monte relatório estruturado (tabela acima) + insights.
4. Idiomas: se o usuário quiser, gere tudo em PT (uma linha de prompt ajusta).
5. Cite fontes (link do anúncio/página) — não invente dado de concorrente.

## 4. Regra

- Foco em EVIDÊNCIA (anúncios ativos, páginas públicas), não em achismo sobre
  a estratégia do concorrente.
