# Catálogo de estilos — carrossel

O catálogo é o que transforma prints soltos em linguagem visual reutilizável.
Cada estilo recebe **número fixo** (nunca renumere; o usuário escolhe pelo número).

## Como montar

1. Buscar referências no Instagram/TikTok com hashtag `carrossel` (em inglês rende mais repertório).
2. Printar 10–15 carrosséis que você gostaria de ter feito — capa **e** miolo.
3. Salvar em `referencias-carrossel/` (pode haver uma segunda pasta de personalidade).
4. Pedir à skill para ler a pasta, agrupar por estilo e numerar.
5. Referência é só linguagem visual: @, foto e texto de outro perfil nunca vão para o slide.

## Ficha de cada estilo

```text
Número:
Nome:
Paleta (hex):
Tipografia (título / corpo):
Textura/fundo:
Layout de capa:
Tratamento de imagem/mascote:
Densidade de texto:
Quando usar:
Custo (código | imagem):
```

## Regras do catálogo

- Estilo novo só entra se pelo menos 2 prints apontarem para ele.
- Estilo que o usuário nunca escolhe em 5 runs: marcar como arquivado (não apagar).
- Cada correção visual do usuário vira uma linha na ficha do estilo (ex.: "título nunca abaixo de 72px").
