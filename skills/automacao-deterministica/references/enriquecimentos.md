# Automação Determinística — Enriquecimentos (YouTube 2026-09-20)

## Freedom level (Nate Herk) — YouTube 2026-09-20

- Fonte `9KOtMsZ9I28` (Nate Herk, "How to Build Codex Skills Better than 99% of People"), passo 3: antes de escrever a skill, posicionar o processo no espectro determinístico↔julgamento — "dá para automatizar com regras duras (x > 10?)" vs "precisa de judgment (analise, transforme, adapte)?".
- Regra: processo determinístico (ex.: planilha→CRM) → skill prescritiva passo-a-passo ("step one do this, step two do this"); processo com judgment (ex.: artigo por vídeo, todo output único) → skill permissiva com definition of done, sem marcar screenshot no minuto 1/2/5 (vira genérico). Escrever skill não-determinística como se fosse determinística = erro; e vice-versa.
